## Alur Data

### 1. Registrasi Akreditasi

```
Client → API Gateway → Akreditasi Module → Database (MySQL)
                                        → Blockchain Service → Besu Node
                                        → IPFS Service → IPFS Node
```

### 2. Upload Dokumen

```
Client → API Gateway → Dokumen Module → IPFS Service → IPFS Node (store file)
                                     → Blockchain Service → Besu Node (store hash)
                                     → Database (store metadata)
```

### 3. Verifikasi Dokumen

```
Client → API Gateway → Dokumen Module → IPFS Service → IPFS Node (get file)
                                     → Calculate SHA256
                                     → Blockchain Service → Besu Node (verify hash)
```
